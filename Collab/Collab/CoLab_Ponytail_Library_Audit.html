💡 Ponytail Audit Findings & Optimization Directives
1. Drop @signalapp/libsignal-client from frontend/app/package.json
Finding: @signalapp/libsignal-client is a Node-only Rust NAPI binding that fails in browsers and is already aliased to false in next.config.js. The actual production E2EE engine runs entirely on the browser's hardware-accelerated crypto.subtle (Web Crypto API). Removing this drops 15MB from the dependency tree with zero functionality change.
2. Exemplary Zero-ORM Database Architecture (mysql2)
Commendation: The backend avoids bloated ORMs like Prisma (~45MB query engine binary) or TypeORM. Pure parameterized SQL via mysql2 provides instant startup, minimal memory consumption, and clean query traceability.
3. Modular Rich Text Editor (TipTap Suite)
Commendation: TipTap is cleanly tree-shaken and modularized. Only the required extensions (mentions, code blocks, lists) are loaded into the chat composer.
